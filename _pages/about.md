Hi, I'm Tereza, a data engineer based in Trento with a master's in data science. Writing code is getting cheaper. Deciding how a system should be built is not. That's the part I focus on: how data is modelled, where it lives, how it moves through a pipeline, and which rules the system itself should enforce so they never depend on someone remembering them. My thesis with FBK was a pipeline that detects individual trees in aerial photos across Italian cities, built around one spatial database. Before all this, I raced mountain bikes professionally.

## What I work on

| Area | In practice |
|---|---|
| **Machine learning & computer vision** | Object detection and segmentation (DeepForest, SAM2), recommender systems (ALS, embeddings), model validation and calibration |
| **Data engineering** | Batch and streaming pipelines (Spark, Kafka, Airflow), Delta Lake, DuckDB, PostgreSQL, Docker, GPU cloud compute |
| **Geospatial & remote sensing** | Aerial and satellite imagery, GDAL, rasterio, GeoPandas, OSM data, H3 spatial indexing, Google Earth Engine, QGIS |
| **Shipping to production** | Flask web apps, PostgreSQL schema design, deployment on Railway |
| **Data architecture & system design** | Data modelling, layered raw-to-results pipelines, batch vs. streaming design, lakehouse (Delta Lake), schema constraints that enforce business rules, reproducible rebuilds |

## Selected projects

- **[Annotation-free tree crown detection](/portfolio/singletree-detection/):** finds individual trees in open aerial imagery across Italian cities without training labels, using DeepForest and SAM2. MSc thesis with FBK.
- **[Podcast recommendation platform](/portfolio/podcast-platform/):** a hybrid recommender that combines listening behaviour and transcript similarity, built on Kafka, Spark, Delta Lake and Airflow.
- **[Weekend registration system](/portfolio/registration-system/):** a production booking app for a ski school, where PostgreSQL enforces quotas, cutoffs and simultaneous bookings.
